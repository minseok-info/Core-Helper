# Core Helper — 코강 도우미

메이플스토리 강화 코어 스크린샷을 올리면 최적의 코어 조합을 찾아 주는 서비스.

🔗 https://www.core-helper.site

| 폴더 | 역할 | 스택 |
| --- | --- | --- |
| [`frontend/`](frontend) | 업로드 UI, Web Worker 기반 코어 조합 탐색 | Next.js · React · TypeScript |
| [`backend/`](backend) | 스크린샷에서 코어·스킬 아이콘 인식 (템플릿 매칭) | FastAPI · OpenCV · Fly.io |

실행 방법은 각 폴더의 README를 참고하세요.
